# Правила работы ИИ-агентов

## Язык
- Все действия в репозитории выполняются на русском языке.
- На русском оформляются названия веток, коммитов, pull request, описания PR, разделы changelog, комментарии к задачам и отчёты.
- Имена файлов, идентификаторы, API, команды, термины языков программирования и общепринятые технические обозначения не переводятся, если это нарушает совместимость или принятые соглашения проекта.
- Пользователю отвечай на русском, если он явно не переключился на другой язык.

## Работа с репозиторием
- Перед изменениями изучи актуальный `main`, этот файл, `CHATGPT_PROJECT_GUIDE.md` и относящиеся к задаче документы.
- Не предполагай архитектуру по названиям файлов или старым обсуждениям: проверь реальные реализации и связи.
- Вноси минимальные изменения, сохраняй совместимость и синхронизируй исходные и производные файлы через предусмотренные генераторы.
- Не изменяй `main` напрямую для функциональных задач: создай отдельную ветку и pull request.
- Не сливай pull request без прямого указания пользователя.
- Не запускай GitHub Actions вручную без прямого указания пользователя.
- Не заявляй о выполнении сборки, тестов или аппаратной проверки, если они фактически не выполнялись.
- В отчётах отдельно указывай, что проверено по коду, локальными тестами, CI и на реальном оборудовании.

## Pull request
- Используй ровно одну метку `release:*`.
- В описании каждого PR должны быть разделы `## Changelog`, `## Проверки` и `## Проверка оборудования`.
- В `## Changelog` должен быть хотя бы один пункт, в том числе для `release:none`.
- Не сливай PR самостоятельно: окончательное решение о слиянии принимает пользователь.
