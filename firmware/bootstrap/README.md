# LEGO Technic ESP32 — первоначальная прошивка через USB и подготовка OTA

В этой папке находится стартовая прошивка для классической платы ESP32 DevKit / ESP32-WROOM-32. Она создаёт ту же точку доступа Wi-Fi, что и основной проект, и предоставляет возможность обновления прошивки через ElegantOTA. После первоначальной прошивки через USB основную прошивку можно будет загружать через браузер.

## Содержимое папки

- `LEGO_Technic_ESP32_Bootstrap/LEGO_Technic_ESP32_Bootstrap.ino` — исходный код стартовой прошивки.
- `flash_bootstrap.bat` — скрипт для Windows, который устанавливает и настраивает Arduino CLI, устанавливает необходимое ядро платы и библиотеки, включает асинхронный режим ElegantOTA, компилирует скетч и загружает прошивку через USB.
- `install_arduino_cli.ps1` — загружает официальную версию Arduino CLI для Windows x64, если она ещё не установлена.
- `patch_elegantota.ps1` — включает асинхронный режим в установленной библиотеке ElegantOTA.
- `prebuilt/esp32_ota_bootstrap.bin` — бинарный файл, который создаётся автоматической сборкой репозитория после успешной компиляции стартовой прошивки. Это **только бинарный файл приложения**, а не полный образ для первоначальной прошивки чистой ESP32.

## Первоначальная прошивка через USB

1. Скачай репозиторий или клонируй его, сохранив структуру папок.
2. В Windows подключи ESP32 DevKit к USB. Закрой Serial Monitor в Arduino IDE и все остальные программы, которые могут использовать последовательный порт.
3. Запусти `flash_bootstrap.bat` из этой папки. Скрипту может потребоваться подключение к интернету для загрузки Arduino CLI, ядра ESP32 и библиотек. Искать и устанавливать ElegantOTA вручную не потребуется.
4. Выбери последовательный порт, соответствующий ESP32, например `COM3`.
5. Если загрузка завершится ошибкой тайм-аута соединения, повтори попытку и переведи плату в режим загрузки во время установления соединения. На многих платах ESP32 DevKit для этого нужно удерживать кнопку BOOT при начале загрузки и отпустить её, когда начнётся запись.
6. Дождись сообщения `SUCCESS`.

## Загрузка основной прошивки через OTA

1. Подключи телефон или компьютер к сети Wi-Fi `LegoTechnic`.
2. Пароль Wi-Fi: `12345678`.
3. Открой в браузере адрес `http://192.168.4.1/update`.
4. Данные для входа в OTA:
   - Логин: `admin`
   - Пароль: `admin`
5. Загрузи скомпилированный файл приложения основного проекта — `build_firmware_for_esp32.bin`. Его можно скачать из успешного запуска GitHub Actions, в котором создан артефакт прошивки.
6. Дождись завершения загрузки и перезагрузки ESP32. При необходимости повторно подключись к точке доступа, затем открой основной интерфейс по адресу `http://192.168.4.1/`.

Стартовая и основная прошивки компилируются для платы `esp32:esp32:esp32` с использованием ESP32 Arduino Core версии `2.0.9` и стандартной схемы разделов памяти. Поэтому ожидается, что OTA-разделы будут совместимы.

Не меняй целевую плату или схему разделов только в одной из двух прошивок без предварительной проверки совместимости OTA.

## Важные замечания

- `prebuilt/esp32_ota_bootstrap.bin` содержит только образ приложения. **Не записывай его отдельно по адресу `0x0` в память пустой ESP32.** BAT-скрипт компилирует и загружает полный скетч с помощью Arduino CLI, который самостоятельно выбирает правильные адреса записи и необходимые образы.
- Для первоначальной настройки требуется подключение к интернету, если Arduino CLI, ядро ESP32 и необходимые библиотеки ещё не сохранены на компьютере.
- Учётные данные точки доступа и OTA намеренно совпадают с данными основной прошивки. Это стандартные учётные данные проекта, не предназначенные для использования в недоверенной среде. Перед широким распространением готового устройства измени их как в стартовой прошивке, так и в основной.
- Этот скрипт предназначен для первоначальной настройки ESP32 через USB. Для обычных обновлений прошивки используй ElegantOTA после того, как основная прошивка уже запущена.
