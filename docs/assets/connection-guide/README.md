# Иллюстрации к руководству по подключению

Здесь хранятся изображения распиновки и схемы подключения, на которые ссылается [руководство по подключению](../../connection_guide.md).

## Что сюда добавлять

- распиновку конкретной платы ESP32 с указанием модели и ревизии;
- схемы соединений моторных драйверов, OLED, сервопривода и питания;
- отдельные схемы для аппаратных ревизий 1.0, 1.5 и 2.0, если они отличаются.

## Правила

- Используй описательные имена, например `esp32-devkit-v1-pinout.png` или `hardware-1.5-wiring.svg`.
- Указывай модель/ревизию платы и источник изображения.
- Не смешивай распиновки разных плат под одним общим названием.
- Если схема ещё не проверена на реальном железе, явно помечай её как справочную или непроверенную.
- Предпочитай SVG для собственных схем и PNG/JPG для фотографий или исходных изображений.

Сейчас это каталог-назначение; изображения нужно добавить отдельно после проверки, что они соответствуют используемым компонентам.
