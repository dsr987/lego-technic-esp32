## Текущая архитектура main

- Четыре моторных канала A/B/E/F управляются через Adafruit Motor FeatherWing V2 с PCA9685 по I²C, физические выходы M1–M4.
- Два канала C/D управляются отдельным TB6612FNG напрямую от ESP32.
- Канал C закреплён за позиционным модифицированным LEGO PF Servo с аналоговой обратной связью на GPIO35.
- Рулевой сервопривод S подключён сигнальной линией к GPIO27.
- OLED SSD1306 и FeatherWing используют общую I²C-шину GPIO21/GPIO22.

Подробные назначения контактов находятся в [pinout.md](pinout.md) и подтверждаются исходниками прошивки.

## Граница подтверждённого

Исходники подтверждают конфигурацию GPIO, адрес PCA9685, частоту PWM и программную маршрутизацию каналов. Они не подтверждают автоматически допустимые токи, схему питания конкретной платы, качество пайки, тепловой режим и надёжность под нагрузкой.

Перед пайкой и эксплуатацией сверяй точную модель/ревизию FeatherWing, TB6612FNG, разъёмы и источники питания. Не считай документ разрешением подключать неизвестный модуль без проверки маркировки и схемы.

## Принципы дальнейшей работы

1. Не менять GPIO без проверки ограничений ESP32 и обновления схемы.
2. Не менять назначение моторных каналов без синхронного изменения backend и документации.
3. Не смешивать силовые и сигнальные цепи на макетных дорожках, не рассчитанных на моторный ток.
4. Перед испытаниями моторов предусмотреть физическое отключение питания.
5. Отделять подтверждение по коду от CI-сборки и аппаратного тестирования.
