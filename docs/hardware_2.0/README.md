Hardware 1.5 и Hardware 2.0 описываются раздельно. Не считай планируемые разъёмы, драйверы или каналы реализованными, пока они физически не собраны и не проверены.

## Принципы

1. Сначала определить точную модель и ревизию FeatherWing Motor Shield и получить её pinout/schematic.
2. Затем утвердить архитектуру: четыре канала FeatherWing плюс один дополнительный TB6612FNG (ещё два канала), с местом и разводкой под возможный второй дополнительный драйвер.
3. Зафиксировать распиновку каждого разъёма до пайки.
4. Не подключать аккумулятор и моторы к непроверенной переходной плате.
5. Все неизвестные номиналы и назначения помечать как **не подтверждено**, а не угадывать.

## Текущая цель по каналам

Предварительная цель — **6 управляемых DC-каналов**: четыре канала FeatherWing и два канала одного дополнительного TB6612FNG. При компоновке оставить возможность добавить ещё один двухканальный драйвер, чтобы потенциально получить восемь каналов. Это пока архитектурный план, не подтверждённая схема.
