# Аппаратная платформа ESP32

> **Дата диагностики:** 2026-11-05  
> **Инструмент:** esptool v5.6.0  
> **Подключение при диагностике:** USB-UART, COM4  
> **Статус:** параметры микроконтроллера и Flash подтверждены чтением через ROM bootloader.

## Идентификация микроконтроллера

| Параметр | Подтверждённое значение |
|---|---|
| Семейство | Espressif ESP32 |
| Тип чипа | ESP32-D0WD-V3 |
| Ревизия кремния | 3.1 |
| Тактовая частота CPU | До 240 МГц |
| Вычислительные ядра | 2 |
| Радиомодули | Wi-Fi, Bluetooth |
| Кварцевый резонатор | 40 МГц |
| Напряжение Flash | 3,3 В |

## Внешняя Flash-память

| Параметр | Значение |
|---|---|
| Обнаруженный объём | 4 МБ |
| Код производителя (JEDEC) | `0x5E` |
| Идентификатор устройства | `0x4016` |

Объём Flash определён командой esptool `flash-id`. Это физическая ёмкость микросхемы Flash, а не размер доступного приложению раздела.

## Среда диагностики

- Операционная система: Windows.
- Интерфейс подключения: COM4.
- Версия esptool: 5.6.0.
- Команды идентификации и чтения информации о Flash завершились успешно.
- Микроконтроллер корректно перешёл в режим ROM bootloader и ответил на запросы.
- Диагностика выполнялась без стирания и записи Flash.

## Что пока не идентифицировано

Точное коммерческое название платы DevKit, производитель и ревизия PCB, модель установленного модуля и тип USB-UART преобразователя по имеющимся данным не установлены. Для их фиксации нужна маркировка на самой плате и модуле.

MAC-адрес в документацию не включён: для описания аппаратной платформы он не требуется.

## Источник данных

Результаты получены 2026-11-05 при подключении платы к COM4 с помощью esptool v5.6.0:

- `chip-id` — тип и ревизия микроконтроллера, частота кварца и доступные функции;
- `flash-id` — идентификаторы и физический объём Flash.

Документ фиксирует фактически считанные характеристики конкретного экземпляра платы. Он не заменяет проверку электрической схемы, распиновки и периферии.
