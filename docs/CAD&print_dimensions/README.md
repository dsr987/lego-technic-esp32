# CAD и размерная сетка для 3D-печати

Папка содержит чертежи и справочные размеры компонентов, необходимые для проектирования корпусов и переходников, совместимых с LEGO Technic.

## Содержимое

- `drawing_1.png`, `drawing_2.png`, `drawing_3.jpg` — чертежи размерной сетки LEGO Technic.
- `lego_technic_dimension_register.xlsx` — существующий реестр размеров LEGO Technic. Он ведётся отдельно и не заменяется таблицей компонентов.
- `component_dimension_grid.csv` — размеры электронных компонентов, гребёнок, стандартной сетки контактов и типовых макетных плат. Файл открывается в Excel; разделитель столбцов — точка с запятой.
- Другие изображения в папке — дополнительные справочные материалы.

## Статусы размеров

- **Справочный размер** — опубликованный типовой размер, который может отличаться у клонов.
- **Проверить экземпляр** — размер взят из типовой документации, но перед финальной CAD-моделью его нужно сверить с конкретной платой.
- **Ожидает замера** — размер намеренно не указан и должен быть внесён после измерения или получения точного чертежа.

## Правила проектирования

1. Все размеры задаются в миллиметрах.
2. Не считать размеры клонов автоматически идентичными оригиналу без проверки контура, положения разъёмов и высоты компонентов.
3. Для ESP32 проверить USB Type-C, кнопки, антенную зону, высоту модуля и расстояние между рядами выводов.
4. Для FeatherWing отдельно учитывать габарит печатной платы и выступающие клеммники/компоненты.
5. Для самодельного переходника внести наружный контур платы, толщину, межрядье и положение женских Dupont-гребёнок. Это один из ключевых размеров для CAD-корпуса.
6. Для Molex 2/3/4 pin размеры оставлены пустыми намеренно: сначала нужно измерить конкретные разъёмы и по возможности определить серию.
7. Типовые размеры Mini-360 и макетных плат используются как ориентиры. Перед моделированием точной посадки проверять фактические габариты.
