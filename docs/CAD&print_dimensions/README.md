# CAD, размерные сетки и 3D-печать

В этой папке собраны чертежи и справочные размеры, необходимые для проектирования CAD-моделей и корпусов, совместимых с LEGO Technic и электроникой проекта.

### Таблицы размеров
- [lego_technic_dimension_register.xlsx](lego_technic_dimension_register.xlsx) — размерный реестр элементов LEGO Technic и параметры, используемые при проектировании совместимых деталей.
- [electronics_component_dimension_register.xlsx](electronics_component_dimension_register.xlsx) — размерная сетка электронных компонентов проекта: ESP32 DevKit USB-C на 30 контактов, LX-LiSC V2, Mini-360, FeatherWing Motor Shield, гребёнки Dupont, макетные платы и незаполненные поля для замеров разъёмов Molex 2/3/4 pin.

## Как пользоваться таблицами

Все линейные размеры указаны в миллиметрах. Стандартный шаг 2,54 мм соответствует 0,1 дюйма.

В таблицах разделены:
- **справочные размеры** из источников или документации;
- **типовые ориентиры**, которые зависят от производителя;
- **размеры, требующие замера конкретного экземпляра**.

Пустые поля оставлены намеренно, если точный размер ещё не установлен. В частности, не заполнены размеры разъёмов Molex 2/3/4 pin и критичное межрядное расстояние контактов конкретной ESP32. Не подставляйте предполагаемые размеры в CAD-модель как подтверждённые.

## Правила для проектирования корпуса

1. До построения посадочного места сверяйте фактический внешний контур платы с таблицей.
2. Для плат с гребёнками отдельно учитывайте шаг контактов, расстояние между рядами и смещение рядов относительно торцов PCB.
3. Учитывайте не только контур PCB, но и выступающие разъёмы USB-C, клеммники, высоту компонентов, штыри и места пайки.
4. Для окончательной CAD-модели используйте замеры конкретных экземпляров. Клоны внешне похожих плат могут отличаться даже при одинаковом заявленном форм-факторе.
5. После каждого нового замера обновляйте таблицу и источник/статус соответствующей строки.

Размеры, отмеченные как типовые или предварительные, предназначены для компоновки, а не для гарантированной посадки без проверки.
