# Новая распиновка и инструкция подключения

> **Схема старого железа 1.0 / прошивки v0.9.x.** Таблицы ниже описывают ESP32 с двумя отдельными драйверами TB6612FNG и OLED на GPIO25/26. Они сохранены как справка для старой сборки и **не подходят для предрелиза 0.10.0**.
>
> **Важно для 0.10.0:** в черновом PR [#47](https://github.com/dsr987/lego-technic-esp32/pull/47) моторы переводятся на I²C Motor Shield / PCA9685, а OLED и моторная плата используют общую шину SDA GPIO21 / SCL GPIO22. Не подключай новое железо по таблицам ниже. Полную актуальную схему и таблицу каналов A–D зафиксируем после проверки конкретной FeatherWing; до этого эти таблицы являются только исторической документацией.

## 1. Подключение второго TB6612FNG

Второй драйвер обслуживает моторы **C и D**. Первый TB6612FNG обслуживает моторы A и B. Вход `STBY` общий для обоих драйверов и подключается к GPIO4 ESP32.

| Вывод второго TB6612FNG | GPIO ESP32 | Назначение |
|---|---:|---|
| `AIN1` | GPIO13 | Направление мотора C |
| `AIN2` | GPIO14 | Направление мотора C |
| `PWMA` | GPIO23 | PWM скорости мотора C |
| `BIN1` | GPIO32 | Направление мотора D |
| `BIN2` | GPIO33 | Направление мотора D |
| `PWMB` | GPIO2 | PWM скорости мотора D |
| `STBY` | GPIO4 | Общее включение обоих TB6612FNG |

Мотор C подключается к выходам `AO1/AO2` второго драйвера, мотор D — к `BO1/BO2`. Если направление вращения не совпадает с командами интерфейса, сначала используй настройку реверса соответствующего мотора; не меняй GPIO наугад.

### Питание и общие соединения

- `VCC` TB6612FNG — логическое питание 3,3 В.
- `VM` — питание двигателей от предусмотренного для них источника; допустимое напряжение зависит от моторов и схемы питания.
- `GND` ESP32, обоих драйверов и источника питания двигателей должны быть соединены общей землёй.
- `STBY` обоих драйверов подключается к GPIO4.
- Перед первым запуском проверь маркировку контактов на конкретном модуле: расположение выводов у плат-клонов может отличаться.

> **Предупреждение:** GPIO2 — загрузочный (strapping) вывод ESP32, и он используется как PWM мотора D. Убедись, что подключённый модуль не удерживает GPIO2 в неподходящем состоянии во время включения и что ESP32 стабильно запускается. Не подключай моторное питание до проверки распиновки и питания мультиметром.

## 2. Полная таблица GPIO ESP32

Эта таблица описывает текущую конфигурацию из `lego_technic_esp32/hardware_config.h`, `app.cpp` и `battery_monitor.cpp`.

| GPIO ESP32 | Подключение / сигнал | Назначение |
|---:|---|---|
| GPIO2 | TB6612FNG №2 `PWMB` | PWM мотора D |
| GPIO4 | `STBY` обоих TB6612FNG | Общее разрешение работы драйверов |
| GPIO13 | TB6612FNG №2 `AIN1` | Направление мотора C |
| GPIO14 | TB6612FNG №2 `AIN2` | Направление мотора C |
| GPIO16 | TB6612FNG №1 `AIN1` | Направление мотора A |
| GPIO17 | TB6612FNG №1 `AIN2` | Направление мотора A |
| GPIO18 | TB6612FNG №1 `PWMA` | PWM мотора A |
| GPIO19 | TB6612FNG №1 `BIN1` | Направление мотора B |
| GPIO21 | TB6612FNG №1 `BIN2` | Направление мотора B |
| GPIO22 | TB6612FNG №1 `PWMB` | PWM мотора B |
| GPIO23 | TB6612FNG №2 `PWMA` | PWM мотора C |
| GPIO25 | OLED SSD1306 `SDA` | Линия данных I²C дисплея |
| GPIO26 | OLED SSD1306 `SCL` | Тактовая линия I²C дисплея |
| GPIO27 | Сигнал сервопривода | Рулевое управление |
| GPIO32 | TB6612FNG №2 `BIN1` | Направление мотора D |
| GPIO33 | TB6612FNG №2 `BIN2` | Направление мотора D |
| GPIO34 | Аналоговый вход АЦП | Измерение напряжения батареи |

### Примечания

- PWM DC-моторов настроен на частоту 5 кГц с разрешением 8 бит.
- OLED SSD1306 подключён по I²C, обычно с адресом `0x3C`; в текущей конфигурации используются GPIO25 (SDA) и GPIO26 (SCL).
- GPIO34 является входом только для чтения и используется для измерения батареи через резистивный делитель. Не подавай на него напряжение батареи напрямую.
- GPIO32 и GPIO33 заняты направлением мотора D, поэтому в текущей схеме они недоступны для управления светом.
- GPIO21 и GPIO22 сейчас заняты мотором B. Не подключай к ним I²C Motor Shield в текущей конфигурации.
- Для работы двух TB6612FNG у ESP32, драйверов и источника питания двигателей должна быть общая земля.
- После любого изменения GPIO обнови эту памятку и `lego_technic_esp32/hardware_config.h` и проверь схему перед подачей питания.
