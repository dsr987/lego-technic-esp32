# Справочные размеры и размерная сетка

Здесь хранятся исходные справочные материалы для проектирования деталей и корпусов LEGO Technic: размерные сетки, таблицы измерений и изображения компонентов.

## Содержимое

- `drawing_1.png`, `drawing_2.png`, `drawing_3.jpg` — чертежи размерной сетки LEGO Technic.
- `lego_technic_dimension_register.xlsx` — реестр размеров LEGO Technic.
- `component_dimension_grid.csv` — размеры электронных компонентов, гребёнок, стандартной сетки контактов и типовых макетных плат. Разделитель столбцов — точка с запятой.
- Остальные изображения — дополнительные справочные материалы, назначение которых следует уточнять по мере инвентаризации.

## Статусы и правила

- **Справочный размер** — опубликованный типовой размер, который может отличаться у клонов.
- **Проверить экземпляр** — размер взят из типовой документации, но перед финальной CAD-моделью его нужно сверить с конкретной платой.
- **Ожидает замера** — размер намеренно не указан и должен быть внесён после измерения или получения точного чертежа.

Все размеры задаются в миллиметрах. Не считать размеры клонов автоматически идентичными оригиналу без проверки контура, положения разъёмов и высоты компонентов. Размеры в таблицах — рабочая база для проектирования, а не замена контрольному замеру конкретных экземпляров.
