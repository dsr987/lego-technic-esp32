# 3D-модель корпуса

Здесь находится проект корпуса для печати и материалы, необходимые для его дальнейшего редактирования.

## Структура

- [source/](source/README.md) — исходники проекта KOMPAS-3D и связанные файлы.
- [print-files/](print-files/README.md) — готовые файлы для слайсера и печати.
- STEP/STP-экспорт хранится рядом с этой документацией или в отдельной папке экспортов, если файлов станет несколько.

## Правила хранения

1. Сохраняй исходный проект KOMPAS-3D, а не только экспорт STL/STP. Экспорт обычно не сохраняет историю построения и параметры модели.
2. После изменения исходника обновляй экспортируемые файлы, если они предназначены для печати или обмена.
3. Указывай версию KOMPAS-3D, единицы измерения, ревизию модели и статус проверки печатью.
4. Не перезаписывай единственную рабочую модель до проверки новой версии. При необходимости сохраняй ревизии с понятными именами.
5. Перед публикацией убедись, что в проект не попали временные файлы, локальные кэши и личные данные.

Текущий файл `case.stp` — STEP/STP-модель для обмена. Это не заменяет редактируемый исходник KOMPAS-3D; его нужно добавить отдельно, когда он будет готов.
