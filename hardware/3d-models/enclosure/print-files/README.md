# Файлы для 3D-печати

Сохраняй здесь проверенные файлы, готовые для слайсера, например STL или 3MF. Если деталь состоит из нескольких частей, используй понятные имена и указывай ориентацию/особенности печати в отдельной заметке.

Для каждого опубликованного файла указывай ревизию модели и статус: черновик, проверен геометрически или успешно напечатан. Не называй файл проверенным, если физическая печать не выполнялась.
