# Lego Technic ESP32 — моторизация с веб-управлением

Прошивка для контроллера ESP32, превращающая модели Lego Technic в радиоуправляемую технику с управлением со смартфона. Плата самостоятельно поднимает Wi-Fi точку доступа — управление осуществляется из любого браузера без установки сторонних приложений, роутера и подключения к интернету[cite: 12].

Проект развивает концепцию единой универсальной платформы электроники для любых моделей Lego[cite: 12].

Текущая версия прошивки: **0.0.6** | [Подробная техническая спецификация (project_logic.md)](project_logic.md)

---

## Основные возможности

- **Два режима управления:**
  - **Танковый:** два независимых слайдера для управления левым и правым бортом/гусеницей[cite: 12].
  - **Классический:** основной привод (мотор A), рулевое управление (сервопривод) и дополнительный канал (мотор B) для кранов, лебёдок или дамперов[cite: 12].
- **Адаптивный Web-GUI:** тёмный интерфейс с версткой под горизонтальный экран смартфона, визуализацией схем техники, поддержкой Touch-событий и мгновенным сбросом слайдеров при отпускании[cite: 12].
- **Калибровка руля из браузера:** настройка центрального положения (trim) и максимального угла поворота (maxdeg) с сохранением в энергонезависимую память платы[cite: 12].
- **Локальный OLED-дисплей:** отображение выбранного режима, уровня заряда аккумулятора (в вольтах и процентах) и количества подключенных клиентов[cite: 12].
- **Многоуровневая система безопасности:**
  - Автоматическая аппаратная остановка моторов (Watchdog 500 мс) при обрыве Wi-Fi соединения[cite: 12].
  - Предупреждение LOW BATTERY при просадке аккумулятора ниже 6.0 В[cite: 12].
- **Обновление по воздуху (OTA):** прошивка платы прямо с телефона через интерфейс ElegantOTA (`/update`) без необходимости разбирать модель[cite: 12].

## Аппаратная часть

### Компоненты системы

| Компонент | Назначение |
|---|---|
| **ESP32-WROOM-32** | Основной микроконтроллер[cite: 12] |
| **TB6612FNG** | Двухканальный драйвер DC-моторов[cite: 12] |
| **Lego Technic L / XL** | Приводные моторы модели[cite: 12] |
| **Geekservo 360° / SG90** | Сервопривод рулевого управления / механизмов[cite: 12] |
| **OLED SSD1306 (I2C)** | Дисплей 128x64 для индикации статуса[cite: 12] |
| **Mini360 DC-DC** | Понижающий преобразователь (5 В) для питания ESP32 и сервы[cite: 12] |
| **BMS 2S (10A) + 2× 18650** | Аккумуляторный блок питания (7.4 В)[cite: 12] |
| **Делитель 100 кОм / 39 кОм** | Измерительная цепь напряжения батареи[cite: 12] |

### Схема подключений (GPIO)

| Назначение | GPIO | Назначение | GPIO |
|---|---|---|---|
| **TB6612 STBY** | 4[cite: 12] | **TB6612 BIN1 / BIN2** | 19 / 21[cite: 12] |
| **TB6612 AIN1 / AIN2** | 16 / 17[cite: 12] | **TB6612 PWMB** | 22[cite: 12] |
| **TB6612 PWMA** | 18[cite: 12] | **Сигнал сервопривода** | 27[cite: 12] |
| **OLED SDA / SCL** | 25 / 26[cite: 12] | **Замер напряжения (АЦП)** | 34[cite: 12] |

> **Примечание:** Пины с загрузочными функциями (GPIO 0, 2, 5, 12, 15) и линии флеш-памяти в проекте намеренно не используются для исключения сбоев при старте[cite: 12].

## Сборка и прошивка

### Настройка среды окружения
Для успешной компиляции требуется строго **ESP32 Arduino Core v2.0.9**[cite: 12].
*Причина:* В версии ядра 3.x изменён API `ledc`, а библиотека `ESPAsyncWebServer 3.1.0` имеет аппаратную ошибку `ets_printf`[cite: 12].

**Зависимости библиотеки:**
- `ESPAsyncWebServer` (v3.1.0)[cite: 12]
- `AsyncTCP` (v1.1.4)[cite: 12]
- `ArduinoJson`[cite: 12]
- `Adafruit SSD1306` + `Adafruit GFX Library`[cite: 12]
- `ESP32Servo`[cite: 12]
- `ElegantOTA` (в файле `ElegantOTA.h` укажите `#define ELEGANTOTA_USE_ASYNC_WEBSERVER 1`)[cite: 12]

### Первичная прошивка (USB)
1. Откройте проект в Arduino IDE / VS Code[cite: 12].
2. Выберите плату: **ESP32 Dev Module**[cite: 12].
3. Загрузите код из директории `lego_technic_esp32/` в плату[cite: 12].

### Обновление по воздуху (OTA)
1. Подключитесь с телефона к Wi-Fi сети `LegoTechnic`[cite: 12, 13].
2. Перейдите по адресу `http://192.168.4.1/update`[cite: 12, 13].
3. Авторизуйтесь (`admin` / `admin`) и загрузите `.bin` файл новой прошивки[cite: 12, 13].

## Известные аппаратные особенности

- **Ток моторов:** Драйвер TB6612FNG рассчитан на ток 1.2 A на канал (пик 3.2 A)[cite: 12]. Не удерживайте моторы Lego (особенно серии XL) в заблокированном состоянии под нагрузкой[cite: 12].
- **Сервопривод Geekservo 360°:** Это сервопривод постоянного вращения (ширина импульса задает скорость)[cite: 12]. Для точного позиционирования колес рекомендуется использовать стандартный позиционный сервопривод (например, SG90)[cite: 12].
- **Питание и помехи:** При сборке на постоянную плату рекомендуется установить электролитический конденсатор 470–1000 мкФ по силовой линии 7.4 В (VM/GND) для сглаживания импульсных помех моторов[cite: 12].
