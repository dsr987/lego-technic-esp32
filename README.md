# LEGO Technic ESP32

Веб-управление моделями LEGO Technic на базе ESP32. Контроллер создаёт собственную Wi-Fi точку доступа, а управлять моделью можно через браузер смартфона или компьютера — без отдельного приложения и домашнего роутера.

**Текущая версия прошивки: 0.3.3 Refactoring**

> Это подготовительная версия. Работоспособность всех функций необходимо подтвердить на реальной модели до выпуска релиза.

## Демо веб-интерфейса

[**Открыть демо-пульт в браузере**](https://dsr987.github.io/lego-technic-esp32/index.html?v=0.3.3%20Refactoring)

Демо позволяет ознакомиться с интерфейсом без подключения к ESP32. Команды в демо не управляют физической моделью.

## Возможности проекта

- **Четыре DC-мотора A, B, C и D** — управление через два двухканальных драйвера TB6612FNG.
- **Режимы управления** — танковый, классический и тестовый; доступные функции зависят от реализации интерфейса и прошивки.
- **Рулевой сервопривод S** — управление положением и настройками рулевого механизма.
- **Настройки моторов** — индивидуальный реверс и сохранение параметров в энергонезависимой памяти ESP32.
- **Веб-интерфейс** — управление через браузер и обмен командами с контроллером по WebSocket.
- **Мониторинг** — отображение данных батареи, состояния Wi-Fi и подключённых клиентов; вывод информации на OLED SSD1306.
- **Безопасность управления** — предусмотрена остановка моторов при отсутствии команд в течение заданного тайм-аута.
- **OTA** — обновление прошивки через веб-интерфейс ElegantOTA, если функция настроена и доступна в прошивке.

### Ограничения текущей версии

- Управление светом пока не реализовано: `applyLeds()` оставлена пустой.
- Проверка четырёх моторов, сервопривода, остановки при потере связи, OLED и измерения батареи на реальной модели ещё необходима.
- Наличие функции в интерфейсе не означает, что её аппаратная работа уже подтверждена.

## Аппаратная часть

### Основные компоненты

| Компонент | Назначение |
|---|---|
| ESP32-WROOM-32 | Основной контроллер |
| 2 × TB6612FNG | Управление четырьмя DC-моторами |
| LEGO Technic DC-моторы | Приводные механизмы |
| Сервопривод | Рулевое управление или вспомогательный механизм |
| OLED SSD1306, 128 × 64 | Отображение состояния системы |
| DC-DC преобразователь | Питание контроллера и периферии |
| Аккумулятор и система защиты | Питание модели |
| Резистивный делитель | Измерение напряжения батареи |

Номиналы аккумулятора, преобразователя и делителя следует подбирать под фактическую сборку. Перед подключением проверьте допустимые напряжения всех компонентов и общий GND.

### Распиновка ESP32

| Сигнал | GPIO |
|---|---:|
| Общий STBY двух TB6612FNG | 4 |
| Мотор A — AIN1 / AIN2 | 16 / 17 |
| Мотор A — PWM | 18 |
| Мотор B — BIN1 / BIN2 | 19 / 21 |
| Мотор B — PWM | 22 |
| Мотор C — AIN1 / AIN2 | 13 / 14 |
| Мотор C — PWM | 23 |
| Мотор D — BIN1 / BIN2 | 32 / 33 |
| Мотор D — PWM | 1 |
| Сервопривод S | 27 |
| OLED SDA / SCL | 25 / 26 |
| Измерение напряжения батареи | 34 |

Каналы LEDC для моторов: A — 4, B — 5, C — 6, D — 7.

**Важные аппаратные замечания:**

- GPIO1 обычно используется как UART0 TX. В этой конфигурации он назначен на PWM мотора D, поэтому возможны конфликты с последовательным выводом и загрузкой прошивки.
- GPIO32 и GPIO33 используются драйвером мотора D, а не светодиодами.
- TB6612FNG включаются сигналом STBY на GPIO4. В проекте предусмотрено безопасное начальное состояние драйверов.
- Не подавайте напряжение аккумулятора напрямую на GPIO ESP32. Общая земля контроллера и драйверов должна быть подключена правильно.
