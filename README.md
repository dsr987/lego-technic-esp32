# Lego Technic ESP32 — моторизация с веб-управлением

Прошивка для ESP32, превращающая модели Lego Technic в радиоуправляемые машины. 
Плата поднимает локальную Wi-Fi точку доступа — управление осуществляется из любого браузера без установки приложений и интернета.

Текущая версия: **0.0.6** | [Подробная техническая документация](project_logic.md)

## Возможности
- **Два режима управления:** Танковый (два трака) и Классический (газ, руль, доп. механизм).
- **Веб-интерфейс:** Автономный HTML/JS, адаптация под мобильные устройства, управление слайдерами.
- **Безопасность:** Автоматическая остановка при потере связи (Watchdog 500 мс).
- **Экран OLED (SSD1306):** Отображение статуса, заряда батареи (В / %) и подключений.
- **Калибровка и OTA:** Настройка руля из интерфейса и прошивка "по воздуху" через ElegantOTA.

## Сборка и прошивка

### Требования к среде
- **ESP32 Arduino Core:** строго `2.0.9` (из-за совместимости LEDC API и AsyncWebServer).
- **Библиотеки:** ESPAsyncWebServer, AsyncTCP, ArduinoJson, Adafruit SSD1306, ESP32Servo, ElegantOTA.

### Первичная прошивка (USB)
1. Откройте проект в Arduino IDE / VS Code (PlatformIO).
2. Выберите плату `ESP32 Dev Module`.
3. Загрузите прошивку по USB.

### Обновление по воздуху (OTA)
1. Подключитесь к Wi-Fi сети платы (`LegoTechnic`).
2. Перейдите по адресу `http://192.168.4.1/update`.
3. Загрузите собранный `.bin` файл.
