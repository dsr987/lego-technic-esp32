# Lego Technic ESP32 — моторизация с веб-управлением

Прошивка для ESP32, которая превращает модели из Lego Technic в управляемые с телефона машины. Плата сама поднимает Wi-Fi точку доступа, телефон подключается к ней напрямую (роутер и интернет не нужны) и управляет моторами и сервой из браузера.

Проект хобби-уровня, развивается итерациями. Текущая версия: **0.0.6**.

## Назначение

- Моторизовать разные модели Lego Technic одним и тем же набором электроники.
- Переключать тип управления прямо в веб-интерфейсе, без перепрошивки.
- Прошивать плату «по воздуху» (OTA) с телефона, чтобы не разбирать модель и не таскать ноутбук.

## Возможности

- **Два режима управления**, переключаются в интерфейсе, выбранный режим запоминается после перезагрузки:
  - **Танковый**: два независимых слайдера (левая и правая гусеница).
  - **Классический**: слайдер газа (мотор A), руль (сервопривод) и доп. мотор B (лебёдка, кран и т. п.).
- Веб-интерфейс в тёмном стиле: вертикальные слайдеры, SVG-схемы танка и машины, подсказка повернуть телефон в альбомную ориентацию, полноэкранный режим. Всё работает без интернета, внешних CDN нет.
- Слайдеры при отпускании возвращаются в ноль.
- **Калибровка руля** в интерфейсе: смещение центра (+/−) и максимальный угол в градусах. Значения хранятся в энергонезависимой памяти платы.
- **OLED SSD1306**: режим, заряд батареи в процентах и вольтах, число подключённых клиентов, иконка режима.
- **Предупреждение LOW BATTERY** на весь экран при напряжении ниже 6.0 В (2S, 3.0 В на банку). При 0 В считается, что батарея не подключена (отладка по USB), предупреждение не показывается.
- **Защита от потери связи**: если 500 мс нет команд, всё останавливается. Браузер каждые 150 мс подтверждает текущие значения слайдеров.
- **OTA-обновление** через страницу `/update` (ElegantOTA), с авторизацией.

## Железо

| Компонент | Назначение |
|---|---|
| ESP32-WROOM-32 | контроллер |
| TB6612FNG | драйвер двух DC-моторов |
| Lego Technic L / XL мотор | привод |
| Geekservo 360° | руль / вспомогательный механизм |
| OLED SSD1306 (I2C) | дисплей |
| Mini360 | понижающий преобразователь 5 В для ESP32 и сервы |
| HX-2S-JH20 BMS (2S, 10 А) + 2× 18650 HG2 | питание 7.4 В |
| Делитель 100 кОм / 39 кОм | замер напряжения батареи |

Схема питания: аккумуляторы → BMS → выключатель → общая шина. С шины питаются Mini360 (в 5 В для ESP32 и сервы) и вход VM драйвера TB6612. Все GND сводятся в одну точку.

### Распиновка ESP32

| Назначение | GPIO |
|---|---|
| TB6612 STBY | 4 |
| TB6612 AIN1 / AIN2 | 16 / 17 |
| TB6612 PWMA | 18 |
| TB6612 BIN1 / BIN2 | 19 / 21 |
| TB6612 PWMB | 22 |
| Сигнал сервы | 27 |
| OLED SDA / SCL | 25 / 26 |
| Замер батареи (АЦП) | 34 |

Пины с загрузочными функциями (0, 2, 5, 12, 15) и линии флеш-памяти не используются.

## Протокол управления

Браузер и плата общаются по WebSocket (`ws://192.168.4.1/ws`), сообщения в JSON:

```json
{"ch":"A","val":-100}
{"mode":1}
{"trim":20}
{"maxdeg":45}
```

- `ch`: канал (`A`, `B` — моторы, `S` — руль), `val`: от −100 до 100.
- `mode`: 0 — танк, 1 — классика.
- `trim`: смещение центра руля в микросекундах от 1500.
- `maxdeg`: максимальный угол руля, 5–90°.

## Сборка

Проект собирается под **ESP32 Arduino core 2.0.9**. Версию нужно держать именно такой:

- код использует классический ledc API (`ledcSetup` / `ledcAttachPin`), на core 3.x он не соберётся;
- ESPAsyncWebServer 3.1.0 из Library Manager — это форк, известный ошибкой `ets_printf` на core 3.0.2 и новее.

Библиотеки:

- ESPAsyncWebServer 3.1.0
- AsyncTCP 1.1.4
- ArduinoJson
- Adafruit SSD1306, Adafruit GFX Library, Adafruit BusIO
- ESP32Servo
- ElegantOTA (в файле `ElegantOTA.h` нужно один раз заменить `#define ELEGANTOTA_USE_ASYNC_WEBSERVER 0` на `1`)

Плата в Arduino: `esp32:esp32:esp32` (ESP32 Dev Module).

Код лежит в `lego_technic_esp32/app.cpp`, а `lego_technic_esp32.ino` намеренно пустой. Препроцессор Arduino (ctags) спотыкается о большую HTML-страницу в raw-строке, а `.cpp` он не трогает.

## Прошивка

**Первый раз** — по USB, любым способом (Arduino IDE или `arduino-cli compile` + `arduino-cli upload`).

**Дальше — по воздуху:**

1. Изменения в `app.cpp` → commit.
2. GitHub Actions (`.github/workflows/build.yml`) собирает прошивку и публикует `lego_technic_esp32.ino.bin` в разделе Releases.
3. Скачать `.bin` на телефон (пока есть интернет).
4. Подключиться к Wi-Fi точке платы, открыть `http://192.168.4.1/update`, войти и загрузить файл. Плата перезагрузится сама.

Номер релиза (`build-N`) выдаёт GitHub, версия прошивки указана в шапке `app.cpp`. Это разные вещи.

Учётные данные точки доступа и OTA заданы в коде. Перед тем как показывать модель другим людям, смените их.

## Известные ограничения

- **Ток моторов.** TB6612FNG держит 1.2 А на канал постоянно (пик 3.2 А). Lego-моторы при заклинивании берут больше, особенно XL. Не стоит держать механизм в упоре, а при активной эксплуатации нужен радиатор на драйвер.
- **Geekservo 360° — сервопривод непрерывного вращения.** Ширина импульса задаёт скорость, а не угол. «Калибровка угла» для него означает предел хода до механического упора. Для настоящего руля с точной установкой угла нужен позиционный сервопривод (типа SG90).
- **Макетная плата.** Импульсные токи мотора наводят помехи. При окончательной сборке на пайке стоит добавить конденсатор 470–1000 мкФ на питание драйвера (VM/GND) и свести все земли в одну точку.
- **Замер батареи** откалиброван под конкретные резисторы (`BATT_DIVIDER_FACTOR`). При замене резисторов пересчитать: новый = старый × (показание кода / показание мультиметра).

## История проекта

- **Идея.** Осенью закуплен набор плат для моторизации Lego Technic: ESP32, драйвер TB6612FNG, OLED, BMS 2S, аккумуляторы 18650, Lego-моторы и Geekservo. Задумано управление с телефона через веб-интерфейс.
- **Архитектура.** Выбрана точка доступа на самой плате (работает в поле без роутера), управление по WebSocket, режимы «танк» и «классика» вместо жёстко зашитой схемы.
- **Первая прошивка.** Распиновка ESP32 под драйвер, серву, OLED и замер батареи. Защитный таймаут остановки.
- **Веб-интерфейс.** Простая страница заменена полноценным интерфейсом. Внешние CDN убраны, потому что у точки доступа нет интернета.
- **OTA.** Добавлен ElegantOTA, сборка через `arduino-cli`. Выяснилось, что ядро нужно зафиксировать на 2.0.9.
- **Стендовые испытания (0.0.5).** Откалиброван замер батареи. Исправлен дребезг сервы (LEDC-каналы моторов перенесены на 4/5, чтобы не пересекаться с ESP32Servo). Исправлена самостоятельная остановка при удержании слайдера (добавлен heartbeat). Добавлена калибровка руля.
- **0.0.6.** Предупреждение LOW BATTERY с антидребезгом, иконки режимов на OLED.
- **Сборка в облаке.** Настроен GitHub Actions: прошивка компилируется на сервере, готовый `.bin` можно скачать и залить OTA прямо с телефона.

## Планы

- Индикация заряда батареи и уровня Wi-Fi в шапке интерфейса.
- Конфигуратор моторов (Mini / L / XL / Klick) с расчётом оборотов и момента.
- Вывод IP-адреса и статуса на OLED.
- Светотехника: фары и стоп-сигналы на светодиодах.
- Финальная сборка на пайке, разъёмы и корпус (печать из PETG).
