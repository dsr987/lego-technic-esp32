# Lego Technic ESP32 — моторизация с веб-управлением

Прошивка для контроллера ESP32, превращающая модели Lego Technic в управляемую со смартфона технику. Плата сама поднимает Wi-Fi точку доступа, управление идёт из обычного браузера: без приложений, роутера и интернета.

Проект развивает идею единой универсальной платформы электроники для любых моделей Lego, поддерживая до 3 независимых моторов и рулевое управление.

Текущая версия прошивки: **0.3.3 Refactoring**

## Основные возможности

- **Три режима управления**, переключаются в интерфейсе на лету:
  - **Танковый:** два независимых слайдера для левого и правого борта (Моторы A и B).
  - **Классический:** основной привод (Мотор A), руль (Сервопривод) и дополнительный мотор (B или C) для кранов, лебёдок и трансмиссии. Поддержка имитации холостого хода ДВС.
  - **Тестовый:** независимое управление всеми тремя моторами (A, B, C) и сервоприводом (S) для отладки и калибровки механики.
- **GUI 2.0:** Современный адаптивный веб-интерфейс с поддержкой темной и светлой темы, плавными анимациями ползунков, динамическими SVG-схемами техники (подсветка направления, искры при запуске ДВС) и виртуальными приборами (тахометр, спидометр).
- **Калибровка и настройки:** Смещение центра руля (trim), максимальный угол поворота (maxdeg), реверс любого из трех моторов и функция "круиз-контроля" (удержание значения) — всё сохраняется в энергонезависимой памяти (NVS).
- **Светотехника:** Управление передними и задними фонарями с визуальной индикацией на кнопках и на SVG-модели.
- **Мониторинг:** OLED-дисплей (режим, заряд %, вольты, клиенты) + дублирование статуса (Wi-Fi RSSI, батарея) в шапке веб-интерфейса с умными баннерами предупреждения о разряде.
- **Защита:** Программный watchdog (остановка при потере связи >500 мс) и умный расчет процента заряда (обновляется только в покое, чтобы просадка под нагрузкой не считалась разрядом).
- **Обновление по воздуху (OTA):** Прошивка с телефона через страницу ElegantOTA (`/update`), разбирать модель не нужно.

## Аппаратная часть

### Компоненты
| Компонент | Назначение |
| --- | --- |
| **ESP32-WROOM-32** | Микроконтроллер |
| **TB6612FNG** | Двухканальный драйвер DC-моторов (Моторы A и B) |
| **DRV8825** | Драйвер шагового двигателя (используется как контроллер направления и ШИМ для Мотора C) |
| **Lego Technic L / XL / M** | Приводные моторы |
| **Geekservo 360° / SG90** | Рулевой сервопривод или вспомогательный механизм |
| **OLED SSD1306 (I2C)** | Дисплей 128x64 |
| **Mini360 DC-DC** | Понижающий преобразователь (5 В) для ESP32 и сервы |
| **BMS 2S (10 А) + 2× 18650** | Аккумуляторный блок (7.4 В) |
| **Делитель 100 кОм / 39 кОм** | Измерение напряжения батареи |
| **Светодиоды** | Передние (зеленые) и задние (красные) фонари |

### Подключение (GPIO)
| Назначение | GPIO | Назначение | GPIO |
| --- | --- | --- | --- |
| Общий STBY драйверов | 4 | DRV8825 DIR (Мотор C) | 23 |
| TB6612 AIN1 / AIN2 (Мотор A) | 16 / 17 | DRV8825 STEP (Мотор C) | 5 |
| TB6612 PWMA (Мотор A) | 18 | Сигнал сервопривода | 27 |
| TB6612 BIN1 / BIN2 (Мотор B) | 19 / 21 | OLED SDA / SCL | 25 / 26 |
| TB6612 PWMB (Мотор B) | 22 | Замер напряжения (АЦП) | 34 |
| Передний LED | 32 | Задний LED | 33 |

> **Примечание:** Пины с загрузочными функциями (GPIO 0, 2, 12, 15) и линии флеш-памяти намеренно не используются. Каналы ШИМ (LEDC) для моторов жестко заданы как 4, 5 и 6, чтобы избежать конфликта с библиотекой `ESP32Servo`, которая резервирует нижние каналы.

## Сборка и прошивка

### Окружение
Требуется **ESP32 Arduino Core 2.0.9**. Версию менять нельзя:
- В коде используется классический API `ledc` (`ledcSetup`, `ledcAttachPin`), который на ядре 3.x изменён.
- Библиотека `ESPAsyncWebServer` на ядре 3.x вызывает ошибки компиляции.

**Необходимые библиотеки:**
- `ESPAsyncWebServer` (версия 3.1.0, форк lacamera)
- `AsyncTCP` (версия 1.1.4)
- `ArduinoJson`
- `Adafruit SSD1306`, `Adafruit GFX Library`, `Adafruit BusIO`
- `ESP32Servo`
- `ElegantOTA` *(Важно: в файле библиотеки `ElegantOTA.h` замените `#define ELEGANTOTA_USE_ASYNC_WEBSERVER 0` на `1`)*

### Первая прошивка (USB)
Откройте `lego_technic_esp32.ino` в Arduino IDE, выберите плату **ESP32 Dev Module** и загрузите скетч.

### Обновление по воздуху (OTA)
1. Внесите изменения в `app.cpp` и сделайте commit. GitHub Actions автоматически соберет прошивку.
2. Скачайте файл `lego_technic_esp32.ino.bin` из раздела **Releases**.
3. Подключитесь к Wi-Fi сети `LegoTechnic` (пароль: `12345678`).
4. Откройте `http://192.168.4.1/update`, введите логин/пароль (`admin`/`admin`) и загрузите `.bin` файл.

> **Внимание:** Пароли по умолчанию публичны. Смените их в `app.cpp` (строки `WiFi.softAP` и `ElegantOTA.begin`), если модель используется вне домашней мастерской.
