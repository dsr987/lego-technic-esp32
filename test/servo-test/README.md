# Servo Test

Изолированный диагностический скетч для определения фактического диапазона позиционной GeekServo. Не входит в основную прошивку и не меняет её код.

## Запуск

1. Откройте папку `test/servo-test` в Arduino IDE либо соберите через Arduino CLI.
2. Выберите **ESP32 Dev Module** для классического ESP32-WROOM-32.
3. Установите библиотеку **ESP32Servo**.
4. Подключите управляющий сигнал сервы к GPIO27. Это тот же сигнальный вывод, который использует основная прошивка.
5. Питайте серву от подходящего внешнего источника питания. Объедините GND источника и GND ESP32. Не питайте сервопривод от вывода 3V3 платы.
6. Сначала отсоедините балку/механизм от выходного вала, загрузите скетч и подключитесь к Wi-Fi `Servo-Test`, пароль `12345678`.
7. Откройте `http://192.168.4.1/`.

## Управление

- Пресеты: 0°, 45°, 90°, 135°, 180°, 270°, 360°.
- Тонкая настройка: ±5° и ±1°; есть ползунок 0–360°.
- Диапазон управляющих импульсов можно менять отдельно. Начальное значение 1000–2000 µs; пределы интерфейса 500–2500 µs.
- Веб-интерфейс показывает вычисленный импульс, отправляемый сервоприводу.

## Как интерпретировать результат

Здесь «градусы» — это шкала команды, линейно отображаемая на диапазон импульсов. Это позволяет визуально сравнить ход выходного вала, но само по себе не измеряет угол и не определяет модель сервы автоматически. Отметьте положение вала для каждого пресета, используя крестовину/балку как указатель. Если выходной вал достигает механического упора, серва гудит, дрожит, нагревается или потребляет повышенный ток, немедленно вернитесь к меньшему диапазону импульсов и не удерживайте её в упоре.

Если при 0° и 360° вал делает полный оборот и возвращается к тому же положению, это может быть непрерывно вращающаяся серва, а не позиционная. Для непрерывной сервы команда обычно управляет скоростью/направлением, а не абсолютным углом. Не делайте вывод о диапазоне 360° только по карточке товара.

## Электрическая безопасность

- Серва питается от отдельного источника с достаточным токовым запасом; GND источника и ESP32 общий.
- Проверьте допустимое напряжение именно вашей сервы.
- Не меняйте подключение при включённом питании.
- Первые перемещения выполняйте без нагрузки и без установленного рычага.
- GPIO27 — только сигнал управления, не питание сервы.
